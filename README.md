# reHUB

**A peer-support community app for people in recovery: activity-based hubs, private daily check-ins, and an encouraging feed.**

reHUB helps people replace old habits with healthy ones by connecting them through activities they enjoy: riding, gaming, hiking, art, cooking, music and more. Members join small communities ("hubs"), check in with how they're feeling each day, share progress, and meet up safely.

> **reHUB is a peer-support tool, not a substitute for professional care.**
> If you or someone you know is in crisis in the Philippines, call the **NCMH Crisis Hotline at 1553** (free, 24/7) or **911** in an emergency.

Built with **Flutter** and **Firebase**. Runs on Android and the web.

---

## Features

### Getting started
- **Sign up / sign in** with email and password, plus password reset
- **Guest mode** to look around without an account (browse-only), with a one-tap upgrade to a real account that keeps the same session
- **Onboarding** for new members: pick your interests and goals to get matching hub suggestions

### Hubs
- **Discover** hubs with search and Online / Outdoors filters
- **Join and leave** hubs with live member counts
- **Suggest a hub**: members propose new hubs, which admins review before they go live
- **Hub leaders**: whoever suggested a hub leads it; admins can assign or change leaders
- **Activities**: leaders and admins post meetups (date, time, place); members RSVP with "I'm going"

### Feed
- **Members-only posts**: updates are visible only to members of the hub they're posted in
- **Anonymous posting** that can't be traced back to the author
- **Reactions** (Support, Proud, Relate) and **comments** (also optionally anonymous)

### Daily check-in
- Log your mood (Great, Okay, Struggling) with an optional private note
- **Check-in history** calendar colored by mood, monthly summary and streaks
- Choosing "Struggling" surfaces crisis hotline information
- **Check-ins are private**: only you can ever read them

### Chat
- A real-time **group chat per hub**, for members only
- Unread indicators, day separators, and delete-your-own messages

### Safety and moderation
- **Report** posts, comments and chat messages (harassment, substances, self-harm risk, spam, other)
- **Admin review queues** for reports and hub suggestions
- Admins can remove content and delete inactive member-created hubs
- **"Need to talk to someone?"** crisis hotline sheet with tap-to-call
- Meetup locations are only visible to hub members, and meetups must be in public places

### How data is stored (Firestore)

```
users/{uid}                          profile, interests, goals, joinedHubs
users/{uid}/checkins/{yyyy-MM-dd}    private daily check-ins
users/{uid}/posts|comments|reactions private ownership records
hubs/{hubId}                         hub info, member count, leader
hubs/{hubId}/members/{uid}           memberships
hubs/{hubId}/messages/{id}           group chat
hubs/{hubId}/events/{id}             activities (+ /going/{uid} RSVPs)
posts/{postId}                       feed posts (no author id stored)
posts/{postId}/comments/{id}         comments (no author id stored)
hubRequests/{id}                     hub suggestions
reports/{id}                         reports (admins only)
admins/{uid}                         admin list (edited in the console only)
```

Posts and comments deliberately **don't store the author's user id**, so anonymous posts stay anonymous. Ownership is kept privately under the author's own user record.

## Running it yourself

### 1. Prerequisites
- [Flutter SDK](https://docs.flutter.dev/get-started/install)
- [Android Studio](https://developer.android.com/studio) with the Android SDK, the command-line tools, and **NDK (Side by side)**
- [Node.js](https://nodejs.org) (for the Firebase CLI)
- A [Firebase](https://console.firebase.google.com) project (the free Spark plan is enough)

Run `flutter doctor` and make sure **Flutter** and **Android toolchain** are green.

### 2. Firebase setup
1. Create a Firebase project.
2. **Authentication:** enable **Email/Password** and **Anonymous** sign-in.
3. **Firestore:** create a database.
4. Install the tools and connect the app:
   ```
   npm install -g firebase-tools
   firebase login
   dart pub global activate flutterfire_cli
   flutterfire configure --platforms=android,web
   ```
5. **Security rules:** copy `firestore.rules` into Firestore → Rules and **Publish**.
6. **Index:** in Firestore → Indexes, create a composite index on collection `posts`: `hubId` Ascending, `createdAt` Descending.
7. **Make yourself an admin:** in Firestore, create a collection `admins` with a document whose ID is your user's UID (from Authentication → Users), with a field `role: "admin"`.

The 8 starter hubs are created automatically the first time an admin opens the app.

### 3. Run
```
flutter pub get
flutter run -d chrome     # web
flutter run               # connected Android phone
```

To build an installable Android app:
```
flutter build apk --release
```
