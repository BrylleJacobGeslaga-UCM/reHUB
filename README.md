# reHUB

> A support-focused mobile application designed to help individuals recovering from addiction by connecting them with supportive communities and encouraging positive, healthy activities.

---

## About reHUB

**reHUB** is a support-focused mobile application designed to assist individuals recovering from addiction. The application connects users with communities that encourage positive activities, personal growth, and healthy recovery habits.

## Features

* **Supportive Communities** — Connect with people who share similar recovery goals.
* **Recovery Goals** — Set and work toward personal goals.
* **Healthy Activities** — Discover activities that encourage positive habits.
* **Community Support** — Interact with supportive communities and users.

## Disclaimer

reHUB is designed as a **support and community platform** and is not intended to replace professional medical, psychological, or addiction treatment.
